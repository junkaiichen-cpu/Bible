# 约谷 · Bible Fighter

一个以圣经人物为核心的 2.5D 横版动作格斗游戏原型。核心入口是 **本地 2 Player 对打**。

## Build 10 · Duel Combat

当前流程：

**角色选择 → 角色 + 密卷 + 帮手 → 3/2/1 → 同屏 1v1 → Best of 3 → 再战 / 换角色**

### 当前战斗输入

P1：`WASD` + `J/K/L/I/O/6/7`

P2：方向键 + `1/2/3/4/5/8/9`

- 普攻
- 技能 1
- 技能 2
- 替身
- 奥义
- 密卷
- 帮手

方向键负责走位与跳跃；不再把“冲锋”单独占一个战斗按钮，技能 2 承担角色专属突进、控制或特殊位移。

### 当前核心机制

- 普攻 4 段连击与不同终段击飞
- 两枚独立技能槽 / CD
- 技能命中积累奥义点
- 4 格奥义点满后释放奥义
- 替身消耗 1 格奥义点，并进入冷却与无敌
- 连招保护 / 浮空保护趋势
- 受击硬直、击退、震屏、慢镜、粒子反馈
- 密卷：长 CD + 发动期间金刚体
- 帮手：整场 Best of 3 仅一次，跨回合保留
- Best of 3
- 双人移动端触控

这套结构借鉴的是移动端实时横版格斗的高层设计：普攻起手、双技能轮换、替身博弈、秘卷/支援反手、奥义资源与走位；具体代码、素材、招式表现均为本项目原创实现。

### 六名角色的技能方向

- **大卫**：投石索远程起手 + 牧者突进
- **摩西**：杖击控制 + 红海远程区域
- **参孙**：重击 + 强力突进
- **但以理**：祷告防守 + 狮子坑反击
- **以利亚**：火焰射击 + 多段火焰压制
- **保罗**：书信远程 + 宣讲突进

### 密卷与帮手

密卷资料位于 `data/supports.js`，帮手在整场 BO3 中只能使用一次；密卷使用时带有真正的金刚体命中免疫。

### 运行

直接打开 `index.html`，或使用任意静态 HTTP server。桌面壳与网页共用同一套战斗代码。

## 神学与设计边界

技能主题尽量从圣经人物明确记载的身份、经历、工具与关键事件出发；伤害、连招、冷却、金刚体、替身、镜头语言等属于游戏化表达，不等同于经文原文。
