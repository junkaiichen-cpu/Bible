# 约谷 · Bible Fighter

一个以圣经人物为核心的 2.5D 横版动作格斗游戏原型。核心入口已经从“章节模式”切换为 **本地 2 Player 对打**。

## Prototype 04 · Local 2P Versus

当前流程：

**角色选择 → P1 / P2 同屏对战 → 胜负 → 再战 / 换角色**

不再把章节剧情作为主游戏模式。圣经知识通过角色身份、技能主题、人物资料和经文锚点自然进入对战系统。

### 当前系统

- 本地双人同屏 1v1
- P1：WASD + J/K/L/I/O
- P2：方向键 + 1/2/3/4/5
- 角色选择界面
- 六名圣经人物进入可对战框架：大卫、摩西、参孙、但以理、以利亚、保罗
- 5A 普攻连段
- 技能、冲锋、替身、奥义
- 决意资源条
- 命中硬直、击退、连击、无敌帧、震屏、粒子反馈
- 移动端双侧触控操作
- 对战结束后再战 / 换角色
- 人物信息与经文锚点面板

## 角色设计原则

角色技能尽量从圣经明确记载的人物身份、经历、工具和关键事件出发。伤害、连招、冷却、无敌帧、镜头语言等属于游戏化表达，不等同于经文原文。

角色资料位于 `data/characters.js`，战斗框架位于 `game.js`，界面与样式位于 `index.html` / `style.css`。

## 运行

无需构建工具。直接打开 `index.html`，或使用任意静态 HTTP server。
