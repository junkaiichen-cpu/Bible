# 约谷 · Bible Fighter

一个以圣经人物为核心的 2.5D 横版动作格斗游戏原型。核心入口是 **本地 2 Player 对打**。

## Test Build · Windows + Mac

当前可测试流程：

**角色选择 → 角色 + 密卷 + 帮手 → 3/2/1 → 同屏 1v1 → Best of 3 → 再战 / 换角色**

### Windows

仓库已经接入 Electron + electron-builder。每次推送 `main` 会自动构建 Windows x64 Portable EXE。

GitHub Actions：`Build Bible Fighter`

生成物名称：`bible-fighter-windows-x64`

### Mac / 浏览器

同一份 HTML/CSS/JS 可直接在 macOS 浏览器运行，不需要 Electron。

仓库同时接入 GitHub Pages 发布工作流；Pages 配置完成后即可通过仓库对应的 GitHub Pages 地址打开试玩版。

### 桌面壳

`electron/main.cjs` 只负责把同一份 `index.html` 包进桌面窗口，因此 Windows 与浏览器版本共用同一套战斗代码。

## 当前战斗系统

- 本地双人同屏 1v1
- P1：WASD + J/K/L/I/O/6/7
- P2：方向键 + 1/2/3/4/5/8/9
- 5A 普攻连段
- 技能、冲锋、替身、奥义
- 决意资源
- 受击硬直、击退、浮空趋势、震屏
- Best of 3
- 双人移动端触控
- 六名圣经人物：大卫、摩西、参孙、但以理、以利亚、保罗

## 密卷

每位玩家战前选择 1 张密卷。

密卷特点：

- CD 明显长于角色普通技能
- 发动期间拥有真正的金刚体，不会被普通命中打断
- 不属于角色被动系统

当前原型密卷包括火、水、风、土四种方向。

## 帮手

每位玩家战前选择 1 名帮手。

规则：

- 每整场 Best of 3 只能使用一次
- 获得后跨回合保留，不会因为回合结束重新获得
- 主要承担一次性的远程、突进或重击支援

## 角色设计

角色差异主要来自独立技能、攻击方式、移动手感、特效和奥义表现，而不是复杂被动系统。

技能主题尽量从圣经人物明确记载的身份、经历、工具与关键事件出发；伤害、连招、冷却、金刚体、镜头语言等属于游戏化表达，不等同于经文原文。

角色资料集中在 `data/characters.js`；密卷与帮手资料在 `data/supports.js`。
