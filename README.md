# 约谷 · Bible Fighter

一个以圣经人物为核心的 2.5D 像素格斗游戏原型。

## Prototype 01

当前原型聚焦 **大卫 vs 歌利亚**，采用横版竞技格斗的核心节奏：

- 移动 / 跳跃
- 三段普攻
- 投石索远程技能
- 冲锋
- 替身机制
- 奥义
- 血条、硬直、浮空式战斗反馈
- 战斗结束后解锁人物档案

## 圣经设计原则

游戏机制是对圣经人物经历的游戏化表达，不把原创数值、连招和镜头表现当成经文内容。

第一章的经文锚点：**撒母耳记上 17 章**。

## 本地运行

无需构建工具。直接打开 `index.html` 即可运行；也可以使用任意静态 HTTP server。
