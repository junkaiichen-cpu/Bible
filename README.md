# 约谷 · Bible Fighter

一个以圣经人物为核心的 2.5D 横版动作格斗游戏原型。核心入口是 **本地 2 Player 对打**。

## Build 06 · Character Identity

当前流程：

**角色选择 → 3/2/1 倒计时 → 同屏 1v1 → Best of 3 → 再战 / 换角色**

这一版在 Build 05 的格斗基础上，开始让角色本身决定玩法：

- 5A 普攻连段
- 受击硬直、击退与浮空趋势
- 替身无敌位移
- 冲锋无敌
- 技能冷却
- 决意资源与奥义
- **角色独立被动状态**
- 角色专属技能主题
- 双人移动端触控
- 角色信息与经文锚点

### 当前被动方向

- **大卫 · 精准**：通过投石索建立短暂精准状态，强化后续命中。
- **摩西 · 坚定**：杖击后进入坚定状态，下一次命中更强调控制。
- **参孙 · 神力**：进入高风险血量区后，近战爆发进一步提升。
- **但以理 · 不妥协**：祷告技能提供短暂无敌并积累决意。
- **以利亚 · 火热**：远程火焰技能形成独立视觉与攻击语言。
- **保罗 · 坚忍**：保持高机动、远程与持续压迫型定位，后续继续强化资源循环。

这些机制是游戏化表达，不等同于经文原文。

## 操作

P1：`WASD` + `J/K/L/I/O`

P2：方向键 + `1/2/3/4/5`

顺序：普攻 / 技能 / 冲锋 / 替身 / 奥义。

## 角色

目前战斗框架支持：大卫、摩西、参孙、但以理、以利亚、保罗。

角色资料集中在 `data/characters.js`；当前主战斗入口使用 `game4.js`。旧版本文件保留为演进记录。

## 设计原则

技能主题尽量从圣经人物明确记载的身份、经历、工具与关键事件出发；伤害、连招、冷却、无敌帧、镜头语言等属于游戏化表达，不等同于经文原文。
