# 约谷 · Bible Fighter

一个以圣经人物为核心的 2.5D 横版动作格斗游戏原型。核心入口是 **本地 2 Player 对打**。

## Build 05 · Combat Focus

当前流程：

**角色选择 → 3/2/1 倒计时 → 同屏 1v1 → Best of 3 → 再战 / 换角色**

这一版继续向竞技格斗手感推进，重点加入：

- 回合倒计时与 FIGHT 提示
- Best of 3 胜场系统
- 5A 普攻连段
- 受击硬直、击退与浮空趋势
- 连招计数与连招时间窗
- 替身无敌位移
- 技能冷却
- 冲锋无敌
- 决意资源与奥义
- 角色专属技能主题
- 双人移动端触控
- 角色信息与经文锚点

## 操作

P1：`WASD` + `J/K/L/I/O`

P2：方向键 + `1/2/3/4/5`

顺序：普攻 / 技能 / 冲锋 / 替身 / 奥义。

## 角色

目前战斗框架支持：大卫、摩西、参孙、但以理、以利亚、保罗。

角色资料集中在 `data/characters.js`；当前战斗入口使用 `game3.js`。旧版本 `game.js` / `game2.js` 保留为演进记录。

## 设计原则

技能主题尽量从圣经人物明确记载的身份、经历、工具与关键事件出发；伤害、连招、冷却、无敌帧、镜头语言等属于游戏化表达，不等同于经文原文。
