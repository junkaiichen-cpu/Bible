# 约谷 · Bible Fighter

一个以圣经人物为核心的 2.5D 横版动作格斗游戏。当前重点是可真实操作的 Windows 2P 本地对战，并持续向高质量像素横版格斗的战斗手感迭代。

## Windows 下载与运行

**普通玩家不需要安装 Node.js、npm、Electron，也不需要下载源码。**

### 直接下载 Windows x64 版本

[**下载 Bible Fighter Windows x64**](https://github.com/junkaiichen-cpu/Bible/releases/latest/download/Bible-Fighter-Windows-x64.exe)

下载完成后，双击 `Bible-Fighter-Windows-x64.exe` 即可启动。

这是 portable 版本，不需要安装程序；游戏会直接运行。

如果 Windows SmartScreen 显示“Windows 已保护你的电脑”或未知发布者提示，这是因为当前版本尚未使用商业代码签名证书。确认文件来自本仓库的 GitHub Release 后，在 SmartScreen 中选择“更多信息”→“仍要运行”即可。

### 从 GitHub Release 选择版本

[打开所有 Windows Releases](https://github.com/junkaiichen-cpu/Bible/releases)

每个经过发布的 Windows 版本都会先经过源码验证、Electron Renderer 启动检查、打包 EXE smoke test，以及真实的大卫 vs 摩西战斗启动与普攻输入测试，然后才进入 Release。

### Build 18 战斗系统

- 5A **Startup / Active / Recovery** 三阶段
- 连招输入缓存与技能取消窗口
- 空中普攻、空中受击与空中追击
- 浮空连段计数与自动 **浮空保护**
- **落地保护**：空战结束后短暂防止无缝再次压起
- **墙角压制**：重击靠墙产生额外硬直与视觉提示，但不会无限弹墙
- **受击分层**：地面受击、空中受击、重击、墙角受击产生不同反馈
- 替身改为真正的受击逃脱机制：受击或浮空阶段可脱离，带冷却与无敌
- **大卫首轮完整角色层**：
  - 地面 5A 五段拥有明确的牧者型移动节奏与终段重击
  - 空中普攻“空中牧者击”，用于追击和延续浮空
  - **投石索**：独立 Startup / Active / Recovery，可用上方向改变抛射高度
  - **牧者跃步**：带短暂无敌的跳跃突进，可用于追击地面与空中目标
  - **歌利亚之战**奥义：独立短演出、五块石头与终结冲击
  - 投石索蓄力、放射闪光、命中确认与专属像素表现
- **摩西第二角色完整战斗层**：
  - 更慢、更重的普攻节奏，强调中距离控制
  - **杖击**：长距离近战、重击确认
  - **分海**：改变前方空间的区域技能，逼迫对手改变站位
  - **红海**奥义：独立短演出、举杖、分海与终结冲击
- 继承此前版本的命中停顿、受击闪白、重击震屏、残影、像素角色动作、投射物拖尾、攻击框调试与暂停。

### 建议试玩路线

**大卫 vs 参孙**：练习 `5A → 技能取消 → 牧者跃步 → 空中追击`。

**大卫 vs 但以理**：练习投石索远程确认、墙角压制和替身博弈。

**摩西 vs 大卫**：练习杖击控制距离、分海改变空间，以及逼迫大卫进入或退出投石索距离。

奥义资源满后按 `O` / `5`，分别测试“歌利亚之战”和“红海”。

`F5`：战斗层提示；`F6`：摩西提示；`F3`：攻击框调试；`ESC`：暂停。

### 六名角色

- **大卫**：投石索远程起手 + 牧者跃步，当前第一名重点打磨角色
- **摩西**：杖击控制 + 红海空间压制，当前第二名重点打磨角色
- **参孙**：重击 + 强力突进
- **但以理**：祷告防守 + 狮子坑反击
- **以利亚**：火焰射击 + 迦密山压制
- **保罗**：书信远程 + 宣讲突进

### 神学与设计边界

技能主题尽量从圣经人物明确记载的身份、经历、工具与关键事件出发；伤害、连招、冷却、金刚体、替身、镜头语言等属于游戏化表达，不等同于经文原文。
