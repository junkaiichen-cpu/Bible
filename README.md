# 约谷 · Bible Fighter

一个以圣经人物为核心、采用 2.5D 横版动作格斗范式的游戏原型。

## Prototype 02

当前首个可玩角色：**大卫**

战斗场景：**以拉谷 · 少年与巨人**

### 当前系统

- 2.5D 横版战斗视角
- 5A 普攻连段
- 投石索远程起手
- 冲锋位移与短暂无敌
- 2 次替身
- 奥义“**五块石头**”
- 受击硬直、击退与连击计数
- 决意资源条
- 奥义慢镜与屏幕反馈
- 手机触控操作
- 人物档案与经文锚点

## 设计原则

游戏中的人物技能尽量从圣经明确记载的人物身份、经历与关键事件出发；伤害数值、连招、无敌帧、镜头语言等均属于游戏化表达，不等同于经文原文。

大卫的第一章主要锚定《撒母耳记上》第 17 章：牧羊人身份、投石索、歌利亚与以拉谷。

## 操作

桌面端：

- `A / D`：移动
- `W`：跳跃
- `J`：普攻
- `K`：投石索
- `L`：冲锋
- `I`：替身
- `O`：奥义

移动端：直接使用屏幕上的方向与技能按钮。
