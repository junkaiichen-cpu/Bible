# 约谷 · Bible Fighter

一个以圣经人物为核心的 2.5D 横版动作格斗游戏原型。核心入口是 **本地 2 Player 对打**。

## Build 08 · Combat / Scroll / Helper

当前流程：

**角色选择 → 密卷 + 帮手配置 → 3/2/1 → 同屏 1v1 → Best of 3 → 再战 / 换角色**

这一版正式向实时忍者格斗的可玩性靠拢：

- 5A 普攻连段
- 受击硬直、击退与基础浮空
- 替身无敌位移
- 冲锋无敌
- 技能冷却
- 决意资源与奥义
- **角色差异主要来自独立技能与独立特效，不使用被动系统**
- **密卷系统：每名玩家选择 1 张；更长 CD；发动期间金刚体**
- **帮手系统：每名玩家选择 1 名；整场 Best of 3 仅能使用一次**
- 双人移动端触控
- 角色信息与经文锚点

## 操作

P1：`WASD` + `J/K/L/I/O/6/7`

P2：方向键 + `1/2/3/4/5/8/9`

顺序：普攻 / 技能 / 冲锋 / 替身 / 奥义 / 密卷 / 帮手。

## 角色

目前支持：大卫、摩西、参孙、但以理、以利亚、保罗。

角色资料：`data/characters.js`

密卷与帮手资料：`data/supports.js`

当前主战斗入口：`game6.js`

旧版本文件保留为演进记录。

## 设计原则

技能、密卷和帮手的主题尽量从圣经人物明确记载的身份、经历、工具与关键事件出发；伤害、连招、冷却、无敌帧、金刚体持续时间、命中盒与镜头语言等属于游戏化表达，不等同于经文原文。
