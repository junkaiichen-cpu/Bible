# 约谷 · Bible Fighter

一个以圣经人物为核心、采用 2.5D 横版动作格斗范式的游戏原型。

## Prototype 03

当前首个可玩角色：**大卫**

战斗场景：**以拉谷 · 少年与巨人**

### 当前系统

- 2.5D 横版战斗视角
- 5A 普攻连段
- 投石索远程起手
- 冲锋位移与短暂无敌
- 2 次替身
- 奥义“**五块石头**”
- 受击硬直、击退与连击计数
- 决意资源条
- 奥义慢镜与屏幕反馈
- 手机触控操作
- 人物档案与经文锚点
- 六人物角色数据层：大卫、摩西、参孙、但以理、以利亚、保罗
- 阵容预览面板：战斗定位 + 人物主题 + 经文锚点 + 开发状态

## 设计原则

游戏中的人物技能尽量从圣经明确记载的人物身份、经历与关键事件出发；伤害数值、连招、无敌帧、镜头语言等均属于游戏化表达，不等同于经文原文。

角色数据与战斗逻辑逐步分离，方便后续对每个人物先进行经文审核，再制作战斗技能。

大卫的第一章主要锚定《撒母耳记上》第 17 章：牧羊人身份、投石索、歌利亚与以拉谷。

## 操作

桌面端：

- `A / D`：移动
- `W`：跳跃
- `J`：普攻
- `K`：投石索
- `L`：冲锋
- `I`：替身
- `O`：奥义

移动端：直接使用屏幕上的方向与技能按钮。

## 目录

- `index.html`：游戏页面与 HUD
- `style.css`：像素风 UI、响应式和移动端控制
- `game.js`：战斗逻辑与大卫 Demo
- `data/characters.js`：可扩展圣经角色数据层
