# 约谷 · Bible Fighter

一个以圣经人物为核心的 2.5D 横版动作格斗游戏原型。核心入口是 **本地 2 Player 对打**。

## Build 09 · Competitive Combat

当前流程：

**角色选择 → 角色 + 密卷 + 帮手 → 3/2/1 → 同屏 1v1 → Best of 3 → 再战 / 换角色**

### 当前战斗系统

- P1：WASD + J/K/L/I/O/6/7
- P2：方向键 + 1/2/3/4/5/8/9
- 5A 普攻连段
- 技能、冲锋、替身、奥义
- 决意资源
- 受击硬直、击退、浮空趋势、震屏
- Best of 3
- 双人移动端触控
- 六名圣经人物：大卫、摩西、参孙、但以理、以利亚、保罗

### 密卷

每位玩家战前选择 1 张。

- CD 明显长于角色普通技能
- 发动期间拥有真正的金刚体：普通命中不会造成伤害或硬直
- 不属于角色被动系统
- 当前原型：火、水、风、土

### 帮手

每位玩家战前选择 1 名。

- 整场 Best of 3 只能使用一次
- 使用状态跨回合保留
- 主要承担一次远程、突进或重击支援

### 角色设计

不使用复杂被动树。角色差异主要来自：

**独立技能 + 招式节奏 + 攻击方式 + 奥义 + 专属特效**

技能主题尽量从圣经人物明确记载的身份、经历、工具与关键事件出发；伤害、连招、冷却、金刚体、镜头语言等属于游戏化表达，不等同于经文原文。

### 本轮优化

新增 `ui/combat-hud.js` 与 `ui/combat-hud.css`，为密卷/帮手提供独立战术状态层：

- 密卷 READY / CD
- 金刚体 ACTIVE / OFF
- 帮手 AVAILABLE / USED

主战斗引擎仍保持 Build 08 的 `game6.js` 稳定版本，避免在 GitHub API 版本校验冲突期间强行覆盖主入口。
