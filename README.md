# 约谷 · Bible Fighter

一个以圣经人物为核心的 2.5D 横版动作格斗游戏原型。当前重点是可真实操作的 Windows 2P 本地对战构建，并持续向高质量像素横版格斗的战斗手感迭代。

## Build 13 · Skill-Cancel Combat

当前流程：

**角色选择 → 角色 + 密卷 + 帮手 → 3/2/1 → 同屏 1v1 → Best of 3 → 再战 / 换角色**

### Windows 桌面构建

Electron 桌面壳直接启动 `playtest.html`；Windows 构建使用 `electron-builder --win portable` 产出可直接运行的 x64 `.exe`。

GitHub Actions 会在 `main` 每次推送后自动构建 Windows x64 portable 版本，并将 `.exe` 作为 workflow artifact 保存。打包前会运行 `npm run validate`，检查入口、资源和全部战斗 JavaScript 的语法。

### 当前战斗输入

P1：`WASD` + `J/K/L/I/O/6/7`

P2：方向键 + `1/2/3/4/5/8/9`

- 普攻
- 技能 1
- 技能 2
- 替身
- 奥义
- 密卷
- 帮手

### Build 13 战斗底座

- 5A 分为 **Startup / Active / Recovery** 三阶段
- 连招输入缓存，减少快速连按丢段
- 5A 终段具有明确击飞与重击反馈
- 连招长度增加后自动伤害衰减
- 普攻收招阶段提供技能取消窗口
- 被击中后自动终止当前攻击状态
- F3 开启攻击框 / 当前攻击阶段调试
- ESC 战斗暂停 / 继续
- 继承 Build 11/12 的命中停顿、受击闪白、重击震屏、残影、像素角色动作、投射物拖尾与战场层次

### 当前核心机制

- 普攻 5 段连击与终段击飞
- 两枚独立技能槽 / CD
- 技能命中积累奥义资源
- 奥义资源满后释放奥义
- 替身无敌位移与冷却
- 连招保护 / 受击保护趋势
- 受击硬直、击退、震屏与粒子反馈
- 密卷：长 CD + 发动期间金刚体
- 帮手：整场 Best of 3 仅一次，跨回合保留
- Best of 3
- 双人移动端触控（Windows 目标不要求手柄）

### 六名角色的技能方向

- **大卫**：投石索远程起手 + 牧者突进
- **摩西**：杖击控制 + 红海远程区域
- **参孙**：重击 + 强力突进
- **但以理**：祷告防守 + 狮子坑反击
- **以利亚**：火焰射击 + 迦密山压制
- **保罗**：书信远程 + 宣讲突进

### 神学与设计边界

技能主题尽量从圣经人物明确记载的身份、经历、工具与关键事件出发；伤害、连招、冷却、金刚体、替身、镜头语言等属于游戏化表达，不等同于经文原文。
